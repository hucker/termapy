## Pass 1: network ports and boundaries

### Verdict

**`--serve` is sound where it was designed and thin where it was not.** The lifecycle promises
hold: every port opens before anything listens, one client per port, a lost port is reopened
and the URL kept, the stop is a token-checked file and never a signal, `--detach` finds its
child by breadcrumb. What a hostile reviewer finds first is at the edges of pyserial: a
served port has no write timeout, so one blocked write (a client asking for RTS/CTS on a
3-wire device) holds the client slot for the server's life; and the network pump guards
only `ValueError`, which pyserial already catches itself, so every other failure from a
client's option is a thread traceback. Two boundary gaps outside `--serve`: `/edit` reaches
the whole disk from a `--web` session served to the network, and under MCP `/cfg.new` writes
a config that points the person's next session at any network host the agent names.

One High, six Medium, ten Low. Nothing lost data; nothing let a network peer past the port
it was given.

## Pass 2: the agent entry path

Three finders (Opus 5.5; 258k + 256k + 244k tokens), each probing one-shots against scratch

### Pass 2 verdict

**The one-shot is the agent's door, and it has several ways to answer wrong without saying
so.** Lazy connect reads only the outer command, so `-e /run script` and `/repeat cmd=` run
with no port and exit 0; `--run` ignores the script's outcome entirely; `--json` placed before
`-e` is pasted onto the line and reaches the device as bytes on `/term.raw`; `/port.chip` on a
missing port answers success; an empty `-e ""` opens the TUI and hangs. Every one of these is a
case where the agent gets a confident wrong answer rather than an error. The parsing that was
designed (`-e` rest-of-line, `--json` after `-e`, the error envelopes, the gate refusals) holds.

Seven High, twelve Medium, one cluster of Low.

### Pass 3 verdict

**The folder families and the values hold; the config file's lifecycle does not.** Every
family mounts its six verbs from its row, list values are counts with the records in `data`,
the redirect lands where it says and the one creator is one creator. What breaks is around the
`.cfg` on disk: a Save answered at the leave question is overwritten by the load that already
happened; a relative `log_file` an MCP agent sets makes the person's next session append its
log into a config; a rename that fails halfway strands the config where no reader finds it; a
dotted name (every quick network config has one) can be created and never loaded; and the help
system tells every reader, the MCP agent included, that the editor is the way to keep a
setting, a week after `/cfg.save` became the way.

## Across the four passes

**Where the big items are.** Sorting the 18 High findings by what they cost the person or the
agent:

1. **Confident wrong answers on the agent path** (E1, E2, E3, E4, E8): a one-shot that never
   gets its port and exits 0, a `--run` that exits 0 whatever happened, a flag that becomes
   device bytes, a missing port that answers success, a `--json` that is ignored. These are the
   bridge-to-LLM promise failing quietly; an agent cannot tell.
2. **Hangs on the agent path** (E5, E6, E7): an empty `-e`, a `/app.tui` in a script, a closed
   pipe. Each parks an unattended agent.
3. **The config file's lifecycle** (F1, F3, F5, F6): a Save undone by its own load, a rename
   that strands the config, a non-atomic write, a dotted name that cannot be loaded.
4. **Boundaries** (N4, N5, F2): `/edit` from a networked `--web` session, and two ways an MCP
   agent leaves a file that the person's next session acts on (a config pointing at any host; a
   `log_file` that appends into a config).
5. **`--serve`'s one hang** (N1) and the pump's tracebacks (N2).
6. **Help that sends the reader the wrong way** (F7, F8, F9, F10, E10): five High-graded text
   defects, all around `/cfg.save` and config names.

**One pattern under several findings.** Pass 2's `--json` leaks (E3, E11, F16), pass 3's
redirect-in-capture (F14) and the `.list` argument (F13) share a cause: a flag or a redirect is
handled as text on the line in one path and as a parsed option in another. One parse, early,
carried as data, would close them together. Likewise N4, D6 and F17 are one defect, a typed
path joined onto a folder with `/` and never checked, in three places.
