## Root cause: missing single owners, not scattered mistakes

The consistency findings below are symptoms of three mechanism gaps. Fixing the
mechanisms retires each *class* of defect; fixing the strings would only reset
the clock.

1. **Usage messages are ad hoc where the system already knows the answer.**
   Every `Command` carries its `name` and `args=`; the dispatcher knows the
   prefix. Params-based commands already get their usage synthesized
   (`plugins/params.py:289 synthesize_synopsis`, emitted at `repl.py:1293`) and
   show zero drift. All drift (K1, K3, the /help-vs-error mismatches) lives in
   hand-rolled handlers that hand-write `Usage:` strings. Hand-rolled *parsing*
   is a documented boundary; hand-rolled *usage strings* never needed to exist.
   Clincher (Verified): the one central emitter at `repl.py:1293` itself
   hardcodes `/` (`f"Usage: /{name} {usage}"`) — one owner means one fix; 31
   owners produced 25 misses.
2. **Synopsis strings are unvalidated data.** K2's `"{{filename}}"` is malformed
   synopsis data the loader happily accepts. The loader already validates
   COMMAND dicts; synopsis grammar (balanced `{}`/`<>`, no spaces inside groups,
   no literal `{{`) is mechanically checkable at load/test time — the same
   guardrail philosophy as the CFG_HELP coverage test and the fail-loud
   release_prep substitutions.
3. **Canonical helpers exist but are not called.** K5: `config.cfg_history_path`
   is the intended owner, produces a *different filename* than either host, and
   its only caller is its own test — while app.py and cli.py hand-roll copies
   whose fallbacks diverge. One owner, universally called, or the owner rots.
   Smaller instances of the same shape: K4, R4, R9.

## What is sound (verified — the invariants that are expensive to regain)

- **Textual/pyserial confinement holds 100%**, including function-level imports:
  zero Textual in `repl`, `plugins/`, `scripting`, `protocol/`, `profile/`,
  `mcp/`, `serial_engine`, `port_control`; `plugins/` and `scripting.py` also
  zero-pyserial.
- **`CmdResult.value` contract: zero violations** — every data-producing handler
  returns `value=`; side-effect-only handlers deliberately return `value=""`.
  (Closes the 2026-era "~50 handlers missing value=" audit item.)
- **5-handle migration is complete**: zero live flat-field bypasses; every
  apparent leak is a stale comment (A6). External example plugins touch only
  stable handles.
- **`terminal_host.py` is a genuinely clean shared base** (35 methods, 3 public,
  none >80 lines) and the repl↔host cycle one would expect does not exist.
- Hygiene: one TODO in the entire non-vendor source; ruff and ty at zero; error
  message families consistent enough to grep by.

Project-level notes: stale `__pycache__` ghosts of deleted plugins (cosmetic,
gitignored); `os.path` island in `port_control`'s Linux sysfs block (POSIX-only
code, letter-vs-spirit of the pathlib rule — noted, not worth churn).

## Remediation candidates (mechanism-first; instance sweeps as byproducts)

1. **feat/usage-from-declaration** — central usage formatter driven by the
   registered Command's `name` + `args=` + `ctx.prefix` (dispatcher-caught
   `UsageError` or `usage_fail()`); fix the prefix at `repl.py:1293`; migrate
   hand-rolled handlers. Kills K1 + K3 as a class; K7 dies in the sweep.
2. **feat/synopsis-validation** — loader-time synopsis grammar check + registry
   conformance test. Kills K2 as a class.
3. **fix/history-path-unify** — one canonical function, both hosts call it (K5).
4. **chore/extract-shared-helpers** — R1, R2, R4, R9, R10 (optionally R3).
5. **chore/proto-consistency** — K4 + R8 (route through `parse_bool`/`_flag_toggle`).
6. **docs/capability-contract-refresh** — A6 + A7 + K8 rule carve-out.
7. **feat/registry-handle** — A2 promotion (small design first).
8. **refactor/app-mixins** — committed next step after this review: mixin-per-
   cluster extraction (PaletteActionsMixin 24 methods, TitleBarMixin 12,
   FindBarMixin 6 incl. the 130-line method; methods stay on the class so
   bindings/action dispatch keep working), expected 3764 → ~2200 with an honest
   floor of ~1800-2000 — **plus the ratchet**: release_prep fail-loud gate on
   app.py growth vs previous release + CLAUDE.md placement rule, so wave two
